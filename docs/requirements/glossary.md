# Glossary

| Term | Meaning |
|---|---|
| FCRM | Financial Crimes Risk Management function |
| Change request (CR) | Any proposed new product, feature, process change, vendor, geography or customer segment |
| Inherent risk | Risk before controls, likelihood x impact per dimension |
| Control effectiveness | Design effectiveness x operating effectiveness, each 0-1 |
| Residual risk | Inherent risk after mitigation; always > 0 |
| Tier | Low / Medium / High / Critical band of residual risk |
| Gate (G0-G3) | A human checkpoint the workflow cannot pass without an explicit human action |
| Override | A human replacing a system output, with a mandatory reason |
| Context pack | Compact structured summary of a case passed between agent nodes instead of raw documents |
| Chunk | A retrievable passage of policy/framework text with a stable id |
| Examiner pack | Exported bundle of everything needed to explain a decision |
| PEP | Politically exposed person |
| MSB | Money services business |
| RBA | Risk-based approach (FATF) |
